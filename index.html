Class 01 · Computational thinking

¿Qué es un algoritmo?

Un algoritmo es una secuencia finita de instrucciones claras y ordenadas para resolver un problema. No necesita estar escrito en un lenguaje de programación.

Ejemplo: calcular el precio total de tres cuadernos

  1. Entrada: conocer el precio de un cuaderno y la cantidad (3).
  2. Proceso: multiplicar precio × cantidad.
  3. Salida: mostrar el total.
Entrada→Proceso→Salida

Pseudocódigo

INICIO
  LEER precio
  cantidad ← 3
  total ← precio * cantidad
  MOSTRAR total
FIN
Comprueba la secuencia

Si un cuaderno cuesta $4.500, el total de tres es $13.500. El algoritmo funciona igualmente si cambia el precio de entrada.

Class 02 · Python foundations

Variables y tipos de datos

Una variable es un nombre que referencia un valor. En Python utilizamos = para asignar y print() para mostrar el resultado.

nombre = "Ana"       # str: texto
edad = 15            # int: entero
precio = 4500.0      # float: decimal
activo = True        # bool: verdadero/falso
cantidad = 3
total = precio * cantidad
print(total)         # 13500.0
TipoEjemploUtilidad
str"Hola"Texto
int15Enteros
float4.5Números decimales
boolTrueValores lógicos

Recuerda: edad = 15 asigna un valor; edad == 15 comprueba igualdad.
